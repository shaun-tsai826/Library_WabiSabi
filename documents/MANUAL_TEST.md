## 第 0 步：啟動網站

開兩個終端機視窗，各執行一組指令：

```bash
cd ~/Projects/Library_WabiSabi/backend
./mvnw spring-boot:run
```

```bash
cd ~/Projects/Library_WabiSabi/frontend
npm run dev
```

1. 後端出現 `Started LibraryApplication`、前端出現 `Local: http://localhost:5173/` 之後，用 Chrome 打開 <http://localhost:5173>。
2. 按 `F12` 打開開發者工具，出問題時可以看 Console 和 Network 分頁。
3. 開始前先確認是**未登入**狀態：導覽列右側顯示「登入 / 註冊」。

**測 3.2、3.3 之前先設定 Google Books API 金鑰**（3.4～3.7 不需要）

Google 給不帶金鑰的呼叫的每日上限是 0，所以一定要先照 STEPS.md 步驟 12 申請金鑰，填進 `application-local.properties` 的 `google.books.api-key`，再**重新啟動後端**。
確認金鑰可用的方法（把 `你的金鑰` 換成實際的值；這行指令會留在終端機的歷史紀錄裡，不要截圖或貼給別人）：

```bash
curl "https://www.googleapis.com/books/v1/volumes?q=isbn:9780134685991&key=你的金鑰"
```

- 回傳書籍資料 → 金鑰可用，可以測。
- 回傳 `"code": 400` 或 `403` → 金鑰錯誤，或 Books API 還沒啟用（見步驟 12 的常見錯誤）。

**想重測 3.1 時**，在 MySQL Workbench 刪掉 Wabi_Sabi（有收藏的話要先刪收藏，因為有外鍵）：

```sql
DELETE FROM favorites WHERE user_id = (SELECT id FROM users WHERE mobile = '0987654321');
DELETE FROM users WHERE mobile = '0987654321';
```
