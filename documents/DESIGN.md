## 1. 設計原則（侘寂風 Wabi-Sabi）

- 沉靜、簡樸、有呼吸感：高留白、去除多餘裝飾與強烈對比。
- 圓潤細線：所有邊框與分隔線粗 **1.5px**，圓角柔和。
- 留白：卡片與主要區塊的內距（padding）**至少 24px**，卡片內多為 40px 以上。
- 不使用陰影、漸層、動畫（Toast 的淡入淡出除外）。

## 3. 字體與尺寸

- 字體：系統中文無襯線字體，例如 `"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`。
- 頁面標題：約 32px、粗體、置中，下方有一條**短底線**（約 220px 寬、深褐色、1.5px）。
- 內文約 18px；次要文字（標籤、作者、ISBN）用 `--color-text-muted`。
- 主要按鈕文字加字距（約 0.1em），例如「登 入 / 註 冊」的視覺感。
- 版面採 **RWD（響應式設計）**，手機、平板、桌機都要正確呈現，規則見 3.1 節：
  - **寬容器**（首頁、收藏頁）：置中，最大寬度約 1200px。
  - **窄卡片**（登入/註冊、個人頁）：置中，最大寬度約 720px。
  - 螢幕比最大寬度窄時，容器寬度改為 100%，左右保留外距（見 3.1）。

### 3.1 RWD 斷點與調整規則
線稿只畫了桌機版；平板與手機依下表調整，表中沒列到的樣式一律沿用桌機版。

寫法：**先寫桌機版樣式，再用 `@media (max-width: ...)` 覆寫**較窄螢幕的部分（新手較好理解）。
注意：CSS 變數不能放在 `@media` 的條件裡，斷點請直接寫數字（1023px、767px），並在全域 CSS 檔頂部用註解列出。

| 項目 | 桌機（≥ 1024px） | 平板（768～1023px） | 手機（< 768px） |
|---|---|---|---|
| 頁面左右外距 | 24px 以上 | 24px | 16px |
| 卡片內距 | 40px 以上 | 32px | 24px |
| 頁面標題 | 32px，底線約 220px | 28px，底線約 180px | 24px，底線約 120px |
| 內文 | 18px | 18px | 16px |
| 頂部導覽列 | 左 logo、右三個項目，同一列 | 同桌機 | logo 一列置中；三個項目在下一列置中（不使用漢堡選單） |
| 首頁 ISBN 輸入列 | 輸入框約 70%＋按鈕約 30%，同一列 | 同桌機 | 輸入框與「查詢」按鈕上下排列，各自滿寬 |
| 「+ 加入收藏」按鈕 | 靠左，約卡片寬 35% | 約卡片寬 50% | 滿寬 |
| 收藏書籍卡片 | 左：書名與資訊；右：「刪除」垂直置中 | 同桌機 | 書名與資訊在上，「刪除」在下並滿寬 |
| 查詢結果封面（v1.2.0） | 卡片左側 120×180，書籍資訊在右側 | 同桌機 | 封面置中放在上方 100×150，資訊在下方 |
| 收藏卡片封面（v1.2.0） | 卡片最左側縮圖 64×96，書名與資訊在縮圖右側 | 同桌機 | 縮圖 56×84，與書名同一列；「刪除」在下方並滿寬 |
| 收藏頁搜尋框（v1.3.0） | 寬度約 50%，靠左 | 約 70% | 滿寬 |
| 收藏頁種類按鈕列（v1.3.0） | 一列，按鈕太多時自動換行 | 同桌機 | 自動換行；按鈕字級 15px |
| 卡片內種類下拉選單（v1.3.0） | 在作者行下方，寬約 160px | 同桌機 | 在作者行下方，滿寬 |
| 清單／統計切換（v1.4.0） | 副標右側 | 同桌機 | 副標下方，靠左 |
| 總覽數字卡（v1.4.0） | 3 張一列 | 3 張一列 | 上下排成 1 欄 |
| 圓餅圖（v1.4.0） | 甜甜圈在左、圖例在右 | 同桌機 | 甜甜圈在上置中、圖例在下 |
| 折線圖（v1.4.0） | 寬度隨卡片伸縮；每個月都標月份 | 同桌機 | 只標單數月份（1、3、5…月），避免文字重疊 |
| 個人頁資訊（標籤／內容兩欄） | 兩欄 | 兩欄 | 兩欄；寬度 < 360px 時改為上下排列 |
| Toast | 畫面上方置中 | 同桌機 | 寬度最多為螢幕的 90% |

共通規則：
- 最小支援寬度 **320px**；任何寬度下都**不可出現水平捲軸**。
- 按鈕與導覽項目等可點擊區域，高度至少 **44px**，方便手指點擊。
- 長書名、長暱稱要能自動換行（`overflow-wrap: anywhere;`），不可撐破版面。
- `index.html` 需有 `<meta name="viewport" content="width=device-width, initial-scale=1">`（create-vue 預設已有，確認即可）。
- 驗收方式：用瀏覽器開發者工具的「裝置模式」，至少檢查 **375px、768px、1280px** 三種寬度。

## 4. 共用元件

### 4.1 頂部導覽列（所有頁面共用）
- 背景 `--color-surface`，高度約 80～110px，左右內距 24px 以上。
- 左側：`LIBRARY / 侘寂書閣`，其中「侘寂書閣」粗體；點擊回首頁 `/`。
- 右側三個項目，由左至右：
  - 未登入：`首頁` ｜ `我的收藏` ｜ `登入 / 註冊`
  - 已登入：`首頁` ｜ `我的收藏` ｜ `{暱稱} (個人頁)`
- 「我的收藏」與第三項前各有一條 1px 的細直線分隔。
- **目前所在頁面的項目文字加粗**；`登入 / 註冊` 平常為較淺的灰色。
- 已登入時顯示的暱稱，用註冊時輸入的原樣大小寫（例如 `Cooqle`）。
- 未登入時點「我的收藏」，依 BDD 的流程處理（提示並導向登入頁）。

### 4.2 頁面標題
置中粗體標題 ＋ 短底線（見第 3 節）。

### 4.3 卡片
背景 `--color-surface`、邊框 `1.5px solid --color-border`、圓角 12px、內距 40px 以上。

### 4.4 輸入框
白色背景、邊框 `1.5px solid --color-border`、圓角 8px、高度約 48～56px、左側內距約 24px；
上方有一行次要色的標籤文字；placeholder 為較淺的灰色。

### 4.5 按鈕（文字置中、圓角 6px、無邊框）
| 種類 | 背景 | 文字色 | 使用處 |
|---|---|---|---|
| 主要 | `--color-text` | 米白 | 「查詢」「登入 / 註冊」「前往登入 / 註冊」 |

### 4.6 錯誤／警示框（頁面內嵌）
背景 `--color-danger-bg`、邊框 `1.5px solid --color-danger-border`、圓角 8px、文字 `--color-danger-text`、粗體、內距 24px 以上。

### 4.7 空狀態框
虛線邊框（`1.5px dashed --color-border`）、圓角 12px、文字置中、次要色，高度約 200px。

### 4.8 Toast 提示（本文件新增，線稿沒有）
BDD 有許多「跳出提示」（登入成功、已成功加入收藏、已移除收藏等），線稿沒有畫出來，請做成簡單的 Toast 元件：
- 位置：畫面上方置中，3 秒後自動消失，同一時間只顯示一則。
- 樣式：圓角 8px、1.5px 邊框、文字置中；
  - 成功／一般提示：背景 `--color-text`、文字米白
  - 警告：背景 `--color-border`、文字 `--color-text`
  - 錯誤：沿用 4.6 的紅色系
- 用 Vue 自己寫一個小元件即可，不安裝套件。

### 4.9 刪除確認視窗（本文件新增）
BDD 要求刪除前跳出 confirmation 確認視窗。為了簡單，**直接使用瀏覽器內建的 `window.confirm()`**，
文字建議為「確定要移除這本書的收藏嗎？」。

### 4.10 書籍封面（v1.2.0 新增，線稿沒有）
BDD v1.3.0 要求查詢結果與收藏清單顯示封面。做成可重用的 `BookCover` 元件：
- 圖片網址：`https://covers.openlibrary.org/b/isbn/{ISBN}-M.jpg?default=false`，各處都用中尺寸（-M，寬 180px）。
  `?default=false` 讓沒有封面時回 404，前端才能偵測並改顯示空白框。
- 固定為 2:3 的直式外框，尺寸見 3.1；圖片用 `object-fit: cover` 填滿（各書比例略有不同，上下可能被裁掉一點點）。
- 外框樣式：背景 `--color-bg`、`1.5px solid --color-border`、圓角 4px；不新增顏色。
- 載入中、沒有封面、載入失敗：都只顯示空白外框，**框內不放圖示也不放文字**（延續第 0 節「省略圖示」的原則），也不顯示任何錯誤提示。
- `alt` 文字：`《{書名}》封面`。
- 收藏頁的封面加上 `loading="lazy"`：捲動到附近才開始載入。

### 4.11 種類按鈕（v1.3.0 新增，線稿沒有）
收藏頁用來依種類篩選的一排按鈕（`CategoryChips` 元件）：
- 外觀像小膠囊：圓角 999px、`1.5px solid --color-border`、背景 `--color-surface`、文字 `--color-text`；高度至少 44px（方便手指點）。
- 文字格式：`{種類} ({本數})`，第一個固定是 `全部 ({總本數})`。
- 選中的按鈕：背景 `--color-text`、文字米白（與主要按鈕同色系），並加上 `aria-pressed="true"`。
- 只顯示「全部」＋有書的種類，依 BDD 的種類清單順序排列；按鈕太多時自動換行。
- 選中的種類變成 0 本時（改了種類或刪除之後），自動切回「全部」。

### 4.12 下拉選單（v1.3.0 新增，線稿沒有）
收藏卡片內用來修改種類的下拉選單（`BaseSelect` 元件）：
- 樣式比照 4.4 輸入框：白底、`1.5px solid --color-border`、圓角 8px；高度 44px；寬度約 160px（手機滿寬）。
- 前面加次要色標籤 `種類：`，用 `<label for>` 對應下拉選單。
- 選項依 BDD 的種類清單順序；選完立即存檔，成功時依 BDD 提示 `已更新書籍種類`。

### 4.13 清單／統計切換（v1.4.0 新增，線稿沒有）
- 兩個並排的按鈕 `清單`、`統計`，樣式沿用 4.11 的膠囊按鈕；選中的為深色並加 `aria-pressed="true"`。
- 切換狀態記在網址：清單為 `/favorites`，統計為 `/favorites?view=stats`；重新整理後保留。
- 只在有收藏時顯示。

### 4.14 總覽數字卡（v1.4.0 新增，線稿沒有）
- 3 張小卡片：`收藏總數`（N 本）、`本月新增`（M 本）、`最多的種類`（種類名稱；同數時取種類清單中較前面的）。
- 樣式：4.3 卡片的縮小版（內距 24px）；上方次要色小字為標題，下方為 1.6em 粗體數值。

### 4.15 圓餅圖（v1.4.0 新增，線稿沒有）
- 用 CSS `conic-gradient` 畫成中間挖空的甜甜圈：直徑 200px（手機 160px），中心挖空約 60%，中心顯示 `{N} 本`。
- 顏色：依第 2 節圖表色票，每個種類固定一個顏色；`未分類` 固定用 `--chart-uncategorized`。
- 圖例：每列 `■ {種類}　{本數} 本　{比例}%`，依本數由多到少排列（同數時依種類清單順序）；比例四捨五入到整數。
- 圓餅圖本身對螢幕報讀軟體隱藏（`aria-hidden`），資料由圖例文字提供。

### 4.16 折線圖（v1.4.0 新增，線稿沒有）
- 手寫 SVG（`viewBox` 固定、寬度 100% 隨卡片伸縮）：最近 12 個月（含本月），每個月新增的收藏本數。
- 線條 `--color-text`、1.5px；資料點為小圓點；數值不為 0 的點上方標數字。
- 橫軸標月份 `11月`、`12月`、`1月`…；每年 1 月與第一個月份下方加註年份。縱軸最大值為「最大月份本數」，至少為 1；背景橫線為 `--color-border` 虛線。
- SVG 加上 `role="img"` 與 `aria-label`（例如「最近 12 個月的收藏趨勢」）。

## 5. 頁面規格（共 7 張線稿，對應 4 個路由）

### 5.1 首頁 `/`：三種狀態

**(a) 初始狀態**：`design/home-empty.png`
- 標題：`首頁 — 書籍查詢`
- 標籤 `ISBN 查詢`；輸入框 placeholder：`請輸入 13 位數 ISBN 碼...`；右側主要按鈕 `查詢`（輸入框約佔 70%、按鈕約佔 30%，同一列）。
- 下方空狀態框，文字：`請在上方輸入 ISBN 碼並點擊「查詢」以檢視書籍詳細資訊`。

**(b) 查詢成功**：`design/home-result.png`
- 輸入框保留使用者輸入的 ISBN。
- 下方結果卡片：
  - 次要色小標：`查詢結果 (Search Result)`
  - `書名：{書名}`（粗體、較大）
  - `作者：{作者}`
  - `出版日期：{出版日期}`
