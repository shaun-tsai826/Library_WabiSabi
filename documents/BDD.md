# - 收藏頁可以用書名、作者或 ISBN 搜尋自己的收藏（不分大小寫，可與種類同時使用）

# - 沒有封面或封面服務無法使用時，顯示同尺寸的空白封面框，不顯示錯誤訊息，也不影響其他功能
# v1.2.0 修訂：
# - 書籍來源新增 Open Library 作為備援：本機 → Google Books → Open Library，查到後存回本機
# - Google Books 無法連線時，仍改查 Open Library
# - 只有所有外部來源都明確查無時，才顯示「找不到此書籍」；
#   任一來源無法使用且都沒查到時，顯示「查詢失敗，請稍後再試」
# - Open Library 的出版日期（例如「July 2008」）與 Google Books 相同，照原樣存放與顯示
# - 「找不到此書籍」範例 ISBN 改為 9789999999999（Open Library 實際收錄了 9780000000000）
# v1.1.0 修訂：
# - 新增 Scenario「未登入使用者嘗試訪問個人頁面被拒絕」，提示文字為「請先註冊/登入」
# v1.0.0 修訂說明（與原版的差異）
# - 暱稱規則：僅接受英文字母、數字、- 與 _，長度 1~20，大小寫視為相同
# - 登入/註冊合一，沒有密碼（簡化設計）
# - 書籍來源：先查本機 books 表，查不到再查 Google Books，查到後存回本機
# - ISBN 僅驗格式（去除前後空白後須為 13 碼數字），不驗證檢查碼
# - 手機號碼：10 碼數字且唯一；暱稱（不分大小寫）與手機須同時吻合才登入
# - 登入狀態：使用 HttpSession 搭配攔截器，不使用 Spring Security；登出即清除 Session
# - 按鈕與欄位名稱對齊線稿（DESIGN.md）：「登入 / 註冊」、「刪除」、「登出帳號」、「會員暱稱」

Feature: 書本查詢、會員驗證與個人收藏管理 (Book Search, Auth, and Favorite Management)
  作為一名網站使用者
  我希望能查詢書籍資訊，並在註冊/登入後管理個人的書籍收藏與個人帳號資訊
  以便於我能在不同裝置上安全地維護我的私房閱讀清單

  Background:
    Given 系統中存在以下書籍資料:
      | isbn          | title           | author       | publish_date |

      | nickname | mobile      |
